# Code of Conduct

Murmur follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work.
Harassment or personal attacks aren't tolerated in issues, pull requests or
anywhere else in the project.

To report a problem, open a
[private security advisory](https://github.com/markmiddo/murmur/security/advisories/new)
(it reaches the maintainer privately) or contact the maintainer through their
GitHub profile.
